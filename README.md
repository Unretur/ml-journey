## What is here

### Data Science
Foundational work with NumPy, Pandas, exploratory data analysis, statistics, visualization, NLP, preprocessing, and coursework.

### Machine Learning
Hands-on implementations and experiments covering regression, classification, trees and ensembles, clustering, time series, dimensionality reduction, association rules, model selection, and related exercises.

### Deep Learning
Experiments with ANN, CNN, and RNN architectures using the frameworks represented in the original work.

### Projects
**SupplyGuard** is the main end-to-end ML project in this repository, including data preparation, feature engineering, model training, evaluation, saved artifacts, and MLflow work.

### Deployment
Earlier model-deployment experiments and application code.

## Philosophy

This repository is a record of practical learning: experiments, assignments, mistakes, iterations, and projects. The goal is to understand not only how to train models, but also how to evaluate, deploy, monitor, and eventually productionize them.

> Learning by building, debugging, and shipping.
